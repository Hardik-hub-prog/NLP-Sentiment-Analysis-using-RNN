# NLP-Sentiment-Analysis-using-RNN

📌 Project Overview

This project focuses on Sentiment Analysis using Natural Language Processing (NLP) and a Recurrent Neural Network (RNN). Using the IMDB Movie Reviews dataset containing 50,000 reviews, the model classifies text reviews into two sentiment categories: Positive and Negative.

The project demonstrates an end-to-end NLP pipeline, from raw text preprocessing to tensor conversion, RNN model training, and performance evaluation, achieving 85% accuracy.

🛠️ Technologies & Libraries

Python

Pandas & NumPy – Data handling and manipulation

Regular Expressions (re) – Text cleaning

NLTK – Tokenization, stemming, and stop-word removal

PyTorch – Tensor conversion, RNN architecture, and model training

Scikit-learn – Model evaluation

🔍 Project Workflow

Dataset Exploration: Worked with the IMDB dataset containing 50,000 movie reviews and their corresponding sentiment labels.

Text Preprocessing: Removed HTML tags, URLs, and punctuation using regular expressions.

NLTK-Based Processing: Applied tokenization, stemming, and stop-word removal to clean and normalize the text.

Text Vectorization: Converted processed text into numerical representations suitable for deep learning.

Tensor Conversion: Transformed the vectorized text and sentiment labels into PyTorch tensors.

RNN Model Development: Built a Recurrent Neural Network architecture to learn sequential patterns and contextual information from movie reviews.

Model Training: Trained the RNN model for 10 epochs.

Model Evaluation: Evaluated the trained model and achieved 85% classification accuracy.

🎯 Key Learnings

Applying text cleaning and preprocessing techniques.

Converting textual data into numerical representations and tensors.

Implementing and training an RNN using PyTorch.

Evaluating a deep learning model for sentiment classification.

📊 Results

Dataset: 50,000 IMDB movie reviews

Task: Binary sentiment classification

Architecture: Recurrent Neural Network (RNN)

Training: 10 epochs

Accuracy: 85%
